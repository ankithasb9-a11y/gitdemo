# Task Management System

## Project Description
The Task Management System is a simple Python application that helps users manage their daily tasks.

## Features
- Add new tasks
- View all tasks
- Search for tasks
- Mark tasks as completed
- Delete tasks

## Technologies Used
- Python
- Git
- GitHub

## Project Structure
- `src/` - Application source code
- `data/` - Stores task information
- `tests/` - Contains test cases
- `docs/` - Project documentation

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Run the following command:

```bash
python src/main.py
```
