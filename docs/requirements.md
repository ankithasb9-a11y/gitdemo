# Project Requirements

## Project Name
Task Management System

## Objective
To develop a simple application that helps users organize and manage daily tasks.

## Functional Requirements

1. Users should be able to add new tasks.
2. Users should be able to view all tasks.
3. Users should be able to search for a task using its ID.
4. Users should be able to mark tasks as completed.
5. Users should be able to delete tasks.

## Non-Functional Requirements

1. The application should be easy to use.
2. The application should display clear messages.
3. The application should handle invalid menu choices.
4. The application should have a simple and understandable code structure.

## Future Enhancements

- Save tasks permanently in a file.
- Add task priority.
- Add task due dates.
- Add database integration.
